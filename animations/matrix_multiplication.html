Matrix Size: 100 × 100 Worker Threads: 16 Total Operations: 1,000,000
📌 Operating Systems Design Concept: The Python backend executes a $100 \times 100$ matrix multiplication requiring 1,000,000 scalar multiplication operations. Creating 1,000,000 OS threads concurrently would exhaust system thread stack memory and trigger RuntimeError: can't start new thread. To fulfill the requirement that every multiplication operation runs on a thread, the system uses a fixed pool of 16 native worker threads consuming work items from a bounded task queue. Each thread evaluates term = A[i][k] * B[k][j] and safely updates sum[i][j] += term under cell-level mutex locks.
